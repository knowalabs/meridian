Meridian's `docs/` suite is what a new contributor reads to work on the Meridian CLI itself — not the docs Meridian _generates_ for other projects (those live in the target project's own `docs/`, distinct from this repository's). Read this index first to find the right file; each doc below stays inside its own concern and cross-references the rest rather than repeating it.

| Doc                                                              | Read this when…                                                                                                                                                                                                         |
| ---------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| [architecture.md](architecture.md)                               | You're about to touch a module boundary and need the real layer map — `src/generate/*`, `src/providers/router.ts`, `src/core/vault.ts`, `src/scan/*`, `src/rules/generators.ts` — and the invariants each one protects. |
| [conventions.md](conventions.md)                                 | You're writing new TypeScript and want naming, import, typing, error-handling and formatting rules proven against real files, not guessed.                                                                              |
| [engineer-workflow.md](engineer-workflow.md)                     | You're setting up the repo for the first time, or need the exact command chain to run before calling a change done.                                                                                                     |
| [engineering-standards.md](engineering-standards.md)             | You want the enterprise bar this stack is held to, where the repo already meets it, and the concrete adoption step for each gap.                                                                                        |
| [tech-debt.md](tech-debt.md)                                     | You're deciding what to fix next and want an honest register instead of tribal knowledge.                                                                                                                               |
| [roadmap.md](roadmap.md)                                         | You want to know where this project is headed before adding something that fights its trajectory.                                                                                                                       |
| [security.md](security.md)                                       | You're touching the vault, the artifact write allowlist, or MCP config writing, and need the security invariants spelled out.                                                                                           |
| [cli-reference.md](cli-reference.md)                             | You need the full `meridian` command surface in one table instead of re-reading `src/cli.ts`.                                                                                                                           |
| [provider-matrix.md](provider-matrix.md)                         | You're adding, comparing, or debugging an AI provider and need cost/speed/quality/context data in one place.                                                                                                            |
| [BEHAVIOUR_CONTRACT_TEMPLATE.md](BEHAVIOUR_CONTRACT_TEMPLATE.md) | You're about to change observable behavior and want to pin down what "correct" means before you start.                                                                                                                  |
