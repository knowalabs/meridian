Every `meridian` command as wired in `src/cli.ts`, in one table. Read this instead of re-reading the Commander setup when you need to know what a command accepts. For what each command's underlying module actually does, see [architecture.md](architecture.md).

## Global flags

Available on every leaf command (`addGlobalFlags` in `src/cli.ts` attaches them recursively): `--verbose` (debug output/stack traces), `-q, --quiet` (errors only), `--json` (machine-readable output where supported), `--no-color` (disable colored output).

## Commands

| Command                               | Key flags                                                                                                                              | What it does                                                                                                                                                 |
| ------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `doctor` (alias `dr`)                 | `--online`                                                                                                                             | Checks environment, installed tools, provider readiness, vault health, and this project's kit state. Read-only, always exits 0.                              |
| `install [tool]` (alias `i`)          | —                                                                                                                                      | Installs/configures a tool (`all` for everything; omit for an interactive picker).                                                                           |
| `uninstall [tool]`                    | —                                                                                                                                      | Uninstalls a tool Meridian manages (omit for a picker).                                                                                                      |
| `auth [provider] [key]`               | `--no-verify`                                                                                                                          | Stores an API key in the vault; verifies it against the provider unless `--no-verify` is passed.                                                             |
| `keys list` (alias `ls`)              | —                                                                                                                                      | Lists stored keys, masked.                                                                                                                                   |
| `keys remove <provider>` (alias `rm`) | —                                                                                                                                      | Deletes a stored key.                                                                                                                                        |
| `keys repair`                         | —                                                                                                                                      | Backs up and reinitializes a corrupted vault.                                                                                                                |
| `generate [kinds...]` (alias `gen`)   | `-p/--provider`, `-f/--force`, `--dry-run`, `--estimate`, `-m/--model`, `--concurrency`, `--no-cache`, `--tools`, `--rigor`, `--no-ai` | Reviews the target codebase and generates the AI kit. Kinds default to all; `ci` is opt-in only (adds a GitHub Action running `sync --check`).               |
| `sync`                                | `--check`, `-p/--provider`, `--dry-run`, `--concurrency`, `-m/--model`, `--no-cache`, `--no-ai`                                        | Detects drift between the codebase and the generated kit and refreshes stale files; `--check` reports only and exits 1 on drift (a CI gate, no AI required). |
| `mcp search [query]`                  | —                                                                                                                                      | Searches the MCP server registry.                                                                                                                            |
| `mcp install <id>` (alias `i`)        | —                                                                                                                                      | Installs an MCP server into every detected tool.                                                                                                             |
| `mcp remove <id>` (alias `rm`)        | —                                                                                                                                      | Removes an MCP server from all configs.                                                                                                                      |
| `mcp list` (alias `ls`)               | —                                                                                                                                      | Lists installed MCP servers.                                                                                                                                 |
| `ask [prompt...]`                     | `-p/--provider`, `-m/--model`                                                                                                          | Routes a question to the best available provider; streams on a terminal, buffers when piped or `--json`.                                                     |
| `router`                              | `--prefer`, `--optimize`, `--model <provider> [model...]`                                                                              | Configures router preference, optimization metric, and per-provider model overrides.                                                                         |
| `update`                              | `--self`, `--tools`                                                                                                                    | Updates the CLI and/or installed AI tools.                                                                                                                   |
| `login`                               | —                                                                                                                                      | Cloud Sync placeholder — not implemented yet (`src/commands/update.ts`'s `loginCommand`).                                                                    |

## What this reference does not cover

Flag validation error messages, interactive-picker behavior, and the exact JSON schema of `--json` output — read the relevant `src/commands/*.ts` file for those; this table is for discovering the surface, not its edge cases.
