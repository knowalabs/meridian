# @sonalsithara/knowa — AI Assistant Guide

This project is managed with [Knowa](https://knowa.sh). Everything below
is generated by `knowa generate` — run `knowa sync` after significant
changes to refresh what is stale (hand-edited files are preserved).

| File                                    | Purpose                                                          |
| --------------------------------------- | ---------------------------------------------------------------- |
| `.knowa/context.md`                     | Generated project context                                        |
| `.knowa/rules.md`                       | Canonical rules — source for all instruction files               |
| `CLAUDE.md` / `AGENTS.md` / `GEMINI.md` | Tool-specific instructions                                       |
| `docs/`                                 | Professional docs suite (architecture, conventions, workflow, …) |
| `.claude/agents/`                       | Project-tailored subagents                                       |
| `.claude/skills/`                       | Project workflows as skills                                      |
| `.claude/commands/`                     | Slash commands for everyday tasks                                |
| `.claude/settings.json`                 | Claude Code harness config (permissions, hooks)                  |
| `.knowa/prompts/`                       | Reusable prompts                                                 |
| `.knowa/docs/`                          | AI working notes (codebase review)                               |
| `.knowa/manifest.json`                  | Kit manifest — powers `knowa sync`                               |
